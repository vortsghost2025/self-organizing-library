# AIDE / Obscura Bridge

**Role:** external test-bed bridge for the WE Framework.

This directory does not absorb AIDE into the WE Framework and does not rebrand AIDE code, concepts, or evidence as WE-owned work. It records the interface between the WE research questions and the external architecture used to test them.

## Attribution boundary

### WE Framework owns

- Rosetta Stone / Rosetta Calculus research questions;
- phenotype compact / restore formalization;
- effective temporal context research;
- belief-lattice and ambient constraint-lattice formulation;
- semantic-binding research program;
- failure -> detection -> correction -> constraint-refinement lineage;
- WE causal-slice / cross-domain falsification questions.

### AIDE / Obscura test bed supplies

- the external software architecture and interfaces under test;
- External-Run Veritas mechanisms used by the relevant experiments;
- Obscura adversarial experimental substrate;
- implementation-specific behavior and evidence generated by those tests.

Credit for external-project code and architecture remains with its respective authors/contributors.

Existing AIDE / Obscura branches, commits, fixtures, and evidence roots are historical evidence. They are referenced; they are not moved, rewritten, relabeled in place, or regenerated merely to fit Book 7.

## Bridge contract

A WE Framework experiment against AIDE should declare:

```text
we_claim_id
external_system = AIDE
external_component
frozen_external_ref
input_mapping
output_mapping
claimed_preserved_relation
expected_disposition
observed_evidence_refs
```

The bridge must never imply that passing an AIDE test proves the general WE claim. It provides implementation evidence for the frozen mapped relation only.
